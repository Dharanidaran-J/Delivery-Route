Academic Project Information

RouteGen: Smart Last-Mile Delivery Route Optimizer
Problem Formulation: Multi-Stop Traveling Salesperson Problem (TSP) with Fixed Depot Constraint.
Distance Computation: Great-circle distance calculated via spherical trigonometry (Haversine formula), augmented by urban Manhattan grid network coefficients.
Meta-Heuristic Optimization: Permutation Genetic Algorithm utilizing Ordered Crossover (OX), 2-Opt Inversion Mutation, and Elitist Selection.
Backend & Storage: Python Flask + SQLite with relational persistence of users, locations, and generational convergence telemetry.
